Q: Source are disclosed, but I don't understand how to compile and run the project ?

It's probably caused by the fact I've used an old-fashioned build system, that requires specific environment setup for many projects.

More specificaly, I stayed away from npm + webpack because I disliked the fact a simple Hello World app requires downloading several MBytes of dependencies to run and takes too long to transpile while coding. I used instead the whole BabylonJS library as a single javascript file and two homemade tool libraries (Nabu and Mummu), also as single javascript files.

It has obvious limits, the absence of tree-shaking being the main one, so I've moved on to a more modern setup for new projects in 2026, using Vite.

Anyway, if you want to compile and run a project I set up the old-fashioned way :

If there's instructions in the ReadME, try to follow them.

If you are looking for the libraries Mummu and Nabu, they are available on GitHub.

GitHub copilot or an equivalent might be able to help you at this point.

If you're still having trouble, feel free to reach out for assistance !
